# Gemini2API v1.7.0: Gemini 4 Argon Protocol & Autonomous Agent Hardening

This release brings full upstream protocol compatibility for **Gemini 4 Argon** (`gemini-4-argon`), resilient simulated tool calling for autonomous coding agents, zero-stall cookie jar filtering, and a fully localized English administration console.

---

### Highlights in v1.7.0

#### 1. Gemini 4 Argon Protocol Support
- **81-Element StreamGenerate Payload**: Implemented full protobuf serialization matching Google's latest Web UI specifications (`inner[80]=2` mandatory thinking).
- **15-Element Capability Header**: Probe-verified header structure (`x-goog-ext-525001261-jspb`) synchronized with thinking flags.
- **Dynamic Token Tracking**: Captures `bl` (`cfb2h`) and `f.sid` (`FdrFJe`) tokens from Gemini Web sessions.

#### 2. Autonomous Agent Simulated Tool Calling Hardening
- **Non-Strict JSON Parsing**: Configured `strict=False` in `json.loads` within `app/utils/tools.py` to seamlessly handle unescaped control characters (such as literal `\n` and `\t`) generated by models in string arguments or content fields.
- **Envelope Extraction Fallback**: Added `_unwrap_text_status_envelope` fallback to prevent raw `{"status": "text", "content": "..."}` envelopes from leaking to clients (e.g. Codex Desktop, OpenCode) when trailing syntax fails parsing.
- **Action-Forcing Guidance**: Enhanced default auto tool-choice system prompt instructions to eliminate model hedging and compel tool invocation when user requests involve file, execution, or search actions.

#### 3. Complete English Web Console Localization
- **Default Locale**: Changed default language from `zh-CN` to `en-US` across `static/app/i18n.js` and `static/index.html`.
- **Sign-in & Fallbacks**: Fully translated `login.html`, dashboard metrics, component fallback strings, and `SPONSORS.md` into English.
- **Local QR Cards**: Routed dashboard community cards and image assets through local `/api-assets` to avoid pulling upstream Chinese cards from raw GitHub.

#### 4. Hardened Multi-Account Resilience
- **Google Web Error Failover**: Intercepts generic Google Web error templates and seamlessly fails over to the next healthy account in the pool.
- **180s Reasoning Timeout**: Relaxed request timeouts from 60s to 180s to accommodate extended thinking passes.
- **Zero-Stall Cookie Jar**: Whitelists only `__Secure-1PSID` and `__Secure-1PSIDTS`, eliminating 168-byte stream stalls caused by volatile anti-abuse cookies (`NID`, `SIDCC`, `AEC`).
- **Context Retention**: Preserves full multi-turn conversation history for autonomous coding agents without relying on single-account Google Web session affinity.
